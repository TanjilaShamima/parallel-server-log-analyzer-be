# Demo Guide

1. Start the backend from `server-analyzer-be`.
2. Start the frontend from `server-analyzer-fe`.
3. Login using the mock credentials.
4. Open Logs.
5. Select a log size.
6. Generate logs.
7. Run sequential analysis.
8. Select worker count and run parallel analysis.
9. Open Benchmark and run benchmark.
10. Explain that processing and merging are measured separately.
