# Calculation Details

## Speedup

```text
Speedup = Sequential Time / Parallel Time
```

## Efficiency

```text
Efficiency = Speedup / Number of Workers
```

## Merge Overhead

```text
Merge Overhead % = Merge Time / Total Parallel Time x 100
```

## Suspicious IP Rule

An IP is suspicious if:

- failed login count > 10
- or request count > 1000
